# XPS3 full-emulator integration track

This branch is the full RPCS3-derived emulator track for XPS3. It is separate from the small
`XPS3 Probe` package, whose purpose is to record Xbox UWP hardware evidence.

## Provenance

- Base repository: `https://github.com/emelin2004/rpcs3-xbox.git`
- Base commit: `0c9bcdf51a70f20f560d6a4100b80dfc3776a734`
- Base commit tree: `ca5abb80257ab16a871771a5c62c768d658453bf`
- The user-supplied `rpcs3 de xbox series s.zip` matched this tree exactly.
- RPCS3 and this derivative remain GPL-2.0-only. Existing copyright notices and history are kept.

## XPS3 overlay applied

- Own package identity: `XPS3.Experimental.Emulator`.
- Own development publisher: `CN=XPS3Development`; a matching certificate must be generated by
  the XPS3 build operator. No certificate from the reference packages is reused.
- Own executables and activation class: `xps3_uwp.exe`, `xps3_uwp_importcheck.exe`, `XPS3.App`.
- External storage root changed from `RPCS3/` to `XPS3/`.
- Inherited telemetry upload and automatic update check are compiled out and replaced by offline
  no-op implementations. RPCN and guest network support are separate features and are not enabled
  by this change.

## Evidence status

The imported base contains a real RPCS3 core, PPU/SPU recompilers, LV2/HLE, audio, input and an RSX
Vulkan renderer translated through Mesa Dozen to D3D12. This proves that the repository is more than
a frontend. It does **not** prove that this XPS3 overlay has compiled or that a PS3 title runs on the
user's Xbox. Those states must only be recorded after reproducible builds and hardware logs.

The PC release executables and ChonkyStation3 source supplied by the user are audit references only;
they are not copied into this tree. PC executables cannot be repackaged as Xbox UWP applications,
and ChonkyStation3 is GPL-3.0-only desktop OpenGL/SDL/Qt code rather than an Xbox UWP port. Its
code is not license-compatible for direct combination with this GPL-2.0-only tree.

Static overlay validation:

```sh
python3 uwp/test_xps3_overlay.py
```

The test rejects inherited package identity/publisher/executable names, compiled telemetry/update
sources, inherited external endpoints, the old USB root and foreign author-logo packaging.

External source inputs are pinned in `uwp/XPS3_SOURCE_LOCK.md` and fetched with
`uwp/xps3-fetch-sources.sh`. A source checkout is accepted only when its resolved commit matches
the recorded hash.

After FFmpeg and LLVM have been cross-built and Vulkan headers are available, the XPS3 targets are
configured and built with:

```sh
uwp/xps3-configure-build.sh build-xps3-uwp \
  ffmpeg-install/lib llvm-install/lib/cmake/llvm Vulkan-Headers/include \
  evidence/xps3-uwp-build.log
```

The wrapper performs no downloads and records the source commit/tree plus every recursive submodule
SHA before invoking CMake and Ninja.

All XPS3 dependency/build wrappers accept `XPS3_JOBS=<positive integer>`. On a low-memory builder,
use `XPS3_JOBS=1`; this is substantially slower but prevents the scripts from blindly using every
CPU and exhausting memory while compiling LLVM.
