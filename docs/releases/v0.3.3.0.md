# XPS3 0.3.3.0 — interface Cell Horizon

Versão experimental para Xbox Series X|S em Developer Mode.

## Mudanças

- Biblioteca com maior destaque para o título selecionado e faixa horizontal adaptada ao controle.
- Aba Instalar reorganizada para firmware legítimo, pacotes e licenças encontrados no USB ou armazenamento local.
- Configurações mais legíveis à distância, mostrando somente valores conectados ao núcleo integrado.
- Menu rápido lateral com retomada, encerramento e ajustes que podem ser aplicados durante a execução.
- Publicação automática em GitHub Releases com APPX, dependência, certificado, checksums e instruções.
- Documentação e galeria visual atualizadas.

## Estado técnico

- A integração RPCS3/RPCS3-Xbox está presente no código-fonte.
- O pacote é compilado e assinado automaticamente antes da publicação.
- O frontend e a estrutura do pacote passam pelas verificações estáticas do projeto.
- Esta versão ainda precisa de validação no Xbox Series S para registrar inicialização, firmware, USB, homebrew e jogos individualmente.

Nenhum jogo é classificado como funcional nesta versão sem log e evidência obtidos no XPS3 0.3.3.0 no hardware-alvo. Firmware e jogos não estão incluídos.

## Instalação resumida

No Xbox Device Portal, envie `XPS3_0.3.3.0_x64.appx` e adicione `Microsoft.UI.Xaml.2.8.appx` como dependência. Depois, no Dev Home, defina o tipo do aplicativo como **Game**.
